# Age of Battels

브라우저에서 돌아가는 전투 시뮬레이션 샌드박스입니다. 지형을 칠하고, 색깔별 군대를 배치하고, **전투 시작**을 누르면 병사들이 알아서 싸웁니다.
A browser battle sandbox: paint a map, place armies for up to eight players, press Start and watch them fight.

`index.html`을 열면 바로 실행됩니다. 빌드 과정도, 외부 에셋도 없습니다.

## 어떻게 즐기나

이 게임은 **구경**과 **실험**을 하나로 묶습니다. 궁금한 병종을 도감에서 찾고, 실험실에서 승률을 확인하고, 전장에서 직접 구경하고, 도전 과제로 실력을 확인합니다.

- **전투 구경** — 시작 전에 누가 이길지 예측하면, 끝난 뒤 모의전 10판 결과와 비교해 "이변"을 알려 줍니다. 주요 전사·건물 파괴·베테랑 승급이 전황 알림으로 뜨고, 관전 카메라(V)가 가장 치열한 곳을 따라갑니다. 유닛을 클릭하면 정보 카드가 나옵니다.
- **실험실** — 두 병종을 같은 비용 또는 같은 수로 수십 번 싸워 승률·평균 생존·평균 시간을 냅니다. "모든 병종과 붙여 보기"로 상성표를 만들고, 원하면 전장에서 직접 봅니다. 계산은 웹 워커에서 돌아 화면이 멈추지 않습니다.
- **병종 도감** — 34종 병종의 움직이는 모습, 능력치, 특수 능력, 강한 상대·약한 상대, 출신과 시대, 역사 설명.
- **도전** — 정해진 적군을 제한된 예산으로 꺾는 퍼즐 8개. 예산을 아낄수록 별이 늘어납니다.

## 할 수 있는 것

- **지도 편집** — 풀밭·흙·모래·눈·길·얕은 물·깊은 물, 나무와 바위. 48×48부터 128×128까지, 무작위 지형 생성.
- **유닛 34종, 건물 6종** — 기본 병종 22종과 고유 병종 12종(로마 군단병, 호플리테스, 사리사 밀집병, 사무라이, 란츠크네히트, 재규어 전사, 투척도끼병, 연노병, 케식 궁기병, 개마무사, 화차, 평형추 투석기). 고유 병종마다 필룸 투척, 방진, 휩쓸기, 광기, 연사, 치고 빠지기, 일제 사격 같은 능력이 있습니다.
- **베테랑** — 3·6·10명을 처치하면 계급이 오르고 공격력이 10%씩 늘어납니다.
- **플레이어 8색과 팀** — 같은 팀끼리는 싸우지 않습니다. 대형 단위(1–100명)로 배치하고 태세(공격·방어·고수)를 정합니다.
- **전투** — 상성, 돌격, 범위 피해, 관통, 치유, 지휘 효과. 길 찾기와 성벽 돌파. 일시정지와 ½–4배속.
- **직접 지휘** — 끌어서 선택하고 오른쪽 클릭으로 이동·공격. 구경만 해도 됩니다.
- **결과 화면** — 플레이어별 투입·손실·처치·피해량과 전력 추이 그래프.
- **저장** — 자동 저장, 이름을 붙인 저장, JSON 파일 내보내기·불러오기. 되돌리기·다시 실행.
- 예제 전투 7개, 한국어·영어 전환.

## 구조

| 파일 | 역할 |
| --- | --- |
| `js/data.js` | 지형, 유닛 능력치, 문자열 |
| `js/lore.js` | 병종 이름, 출신, 역사, 능력 설명 |
| `js/labcore.js`, `js/worker.js` | 실험실과 모의전 계산 (워커, 없으면 페이지에서) |
| `js/challenges.js` | 도전 과제 |
| `js/extra.js` | 도감, 실험실, 도전, 관전 화면 |
| `js/scenario.js` | 지도 모델, 편집 연산, 예제 전투 |
| `js/sim.js` | 전투 시뮬레이션 (20Hz 고정 틱, 결정적, DOM 없음) |
| `js/sprites.js` | 절차적으로 그리는 스프라이트 |
| `js/render.js` | 등각 투영 렌더러, 이펙트, 미니맵 |
| `js/audio.js` | Web Audio로 합성하는 효과음 |
| `js/main.js` | 편집기, 입력, UI |

## 테스트

```
node tests/sim.test.cjs            # 예제 전투 완주, 결정성, 상성, 성벽 돌파, 교착 판정
node tests/sim.test.cjs --matrix   # 같은 전력값끼리의 전체 상성표
node tests/bench.cjs               # 약 2,900명 규모의 틱 비용
node tests/unique.cjs              # 고유 병종의 같은 비용 상성
node tests/challenges.cjs          # 도전 과제마다 이길 수 있는 해법이 있는지
node tests/presets-odds.cjs        # 예제 전투가 얼마나 박빙인지
```

## 출처

그림은 전부 이 저장소의 캔버스 코드로 그리고, 소리는 전부 브라우저에서 합성합니다. 외부 스프라이트·텍스처·음원은 들어 있지 않습니다. 유닛은 역사에 흔한 병종(창병, 궁병, 기사 등)이며 특정 게임의 캐릭터나 자산이 아닙니다.
