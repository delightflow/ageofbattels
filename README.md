# Age of Battels

브라우저에서 돌아가는 전투 시뮬레이션 샌드박스입니다. 지형을 칠하고, 색깔별 군대를 배치하고, **전투 시작**을 누르면 병사들이 알아서 싸웁니다.
A browser battle sandbox: paint a map, place armies for up to eight players, press Start and watch them fight.

`index.html`을 열면 바로 실행됩니다. 빌드 과정도, 외부 에셋도 없습니다.

## 어떻게 즐기나

이 게임은 **구경**과 **실험**을 하나로 묶습니다. 궁금한 병종을 도감에서 찾고, 실험실에서 승률을 확인하고, 전장에서 직접 구경하고, 도전 과제로 실력을 확인합니다.

- **전투 구경** — 시작 전에 누가 이길지 예측하면, 끝난 뒤 모의전 10판 결과와 비교해 "이변"을 알려 줍니다. 주요 전사·건물 파괴·베테랑 승급이 전황 알림으로 뜨고, 관전 카메라(V)가 가장 치열한 곳을 따라갑니다. 유닛을 클릭하면 정보 카드가 나옵니다.
- **실험실** — 두 병종을 같은 비용 또는 같은 수로 수십 번 싸워 승률·평균 생존·평균 시간을 냅니다. "모든 병종과 붙여 보기"로 상성표를 만들고, 원하면 전장에서 직접 봅니다. 계산은 웹 워커에서 돌아 화면이 멈추지 않습니다.
- **병종 도감** — 34종 병종의 움직이는 모습, 능력치, 특수 능력, 강한 상대·약한 상대, 출신과 시대, 역사 설명.
- **도전** — 정해진 적군을 제한된 예산으로 꺾는 퍼즐 8개. 예산을 아낄수록 별이 늘어납니다.

## 할 수 있는 것

- **지도 편집** — 풀밭·흙·모래·눈·길·얕은 물·깊은 물, 나무와 바위. 48×48부터 128×128까지, 무작위 지형 생성.
- **유닛 34종, 건물 6종** — 기본 병종 22종과 고유 병종 12종(로마 군단병, 호플리테스, 사리사 밀집병, 사무라이, 란츠크네히트, 재규어 전사, 투척도끼병, 연노병, 케식 궁기병, 개마무사, 화차, 평형추 투석기). 고유 병종마다 필룸 투척, 방진, 휩쓸기, 광기, 연사, 치고 빠지기, 일제 사격 같은 능력이 있습니다.
- **베테랑** — 3·6·10명을 처치하면 계급이 오르고 공격력이 10%씩 늘어납니다.
- **플레이어 8색과 팀** — 같은 팀끼리는 싸우지 않습니다. 대형 단위(1–100명)로 배치하고 태세(공격·방어·고수)를 정합니다.
- **전투** — 상성, 돌격, 범위 피해, 관통, 치유, 지휘 효과. 길 찾기와 성벽 돌파. 일시정지와 ½–4배속.
- **직접 지휘** — 끌어서 선택하고 오른쪽 클릭으로 이동·공격. 구경만 해도 됩니다.
- **결과 화면** — 플레이어별 투입·손실·처치·피해량과 전력 추이 그래프.
- **저장** — 자동 저장, 이름을 붙인 저장, JSON 파일 내보내기·불러오기. 되돌리기·다시 실행.
- 예제 전투 7개, 한국어·영어 전환.

## 3D 에셋 (Blender)

유닛·건물·나무 그림은 Blender로 만든 3D 모델을 미리 렌더링한 스프라이트입니다(고전 RTS와 같은 방식). 모델은 이미지 파일이 아니라 `tools/bake/bake.py` 코드로 조립합니다. 관절이 있는 사람·말·낙타·코끼리·늑대, 공성 무기, 성벽·탑·성채, 나무와 바위를 만들고, 병종 정의(`js/data.js`의 투구·갑옷·무기·방패)를 그대로 읽어 입힙니다.

- 유닛마다 5방향 × 20프레임(서 있기 1, 걷기 8, 공격 6, 쓰러짐 5)을 Cycles로 렌더링합니다. 나머지 3방향은 게임에서 좌우 반전합니다.
- 팀색 부분만 한 번 더 렌더링한 마스크(`*_m.webp`)로 8가지 플레이어 색을 입힙니다.
- 구운 파일은 `assets/sprites/`에 있고, 없거나 아직 불러오는 중이면 예전 손그림 스프라이트를 씁니다.

다시 굽기:

```
pip install bpy pillow numpy                     # Blender 5.x 파이썬 모듈
node tools/bake/export-looks.cjs > tools/bake/looks.json
python tools/bake/bake.py -- assets/sprites      # 전부 (약 1시간), 또는 뒤에 id를 나열
python tools/bake/finish.py assets/sprites       # 셀 다듬기, 아이콘 시트, manifest.js
PREVIEW=1 python tools/bake/bake.py -- /tmp/prev knight   # 3방향 8프레임만 빠르게
```

## 소리 (ElevenLabs)

효과음과 배경 소리는 ElevenLabs 효과음 생성 API로 만든 클립입니다(`assets/audio/`, 52개, 약 1.6MB). 칼 부딪힘·베기·막기·도끼·찌르기, 활·석궁·화승총·대포·투석기·화차, 비명과 신음, 말·코끼리·늑대, 성벽 붕괴, 뿔나팔·함성·승리와 패배, 그리고 반복 재생하는 전투 북소리·전장 소음·야영지 분위기가 있습니다. 게임은 재생할 때마다 음높이와 크기를 조금씩 바꾸고, 파일을 불러올 수 없을 때(`file://`)는 브라우저 합성음으로 대신합니다.

```
ELEVENLABS_API_KEY=... python3 tools/audio/gen.py      # tools/audio/raw/ 에 생성 (키는 파일에 저장하지 않음)
python3 tools/audio/pack.py                            # 다듬고 크기를 맞춰 assets/audio/ 로
```

## 출처

그림은 전부 이 저장소의 코드로 만듭니다(Blender 모델 스크립트와 캔버스 그리기). 소리는 ElevenLabs(https://elevenlabs.io)로 생성했습니다. 소리는 전부 브라우저에서 합성합니다. 외부 스프라이트·텍스처·음원은 들어 있지 않습니다. 유닛은 역사에 흔한 병종(창병, 궁병, 기사 등)이며 특정 게임의 캐릭터나 자산이 아닙니다.
