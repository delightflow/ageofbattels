# Credits

Age of Battels is an original browser battle sandbox. Troop names are historical types (legionary, hoplite, longbowman, janissary, and so on). They are not characters, units, or trademarks from any commercial strategy game.

## Audio

All battle sound is synthesized in the browser with the Web Audio API: arrow volleys, impacts, melee, cavalry, deaths, dice ticks, ambience, and music. No sampled audio files are shipped.

An earlier `bgm_battle.mp3` had no artist, title, or license in its metadata, so it was removed rather than published with the game.

## Art and code

Unit drawings, the battlefield, and the interface are original canvas and CSS work in this repository. No third-party sprites or textures are bundled.

The page can load Cinzel, Literata, and IBM Plex Mono from Google Fonts. If that request fails, the layout falls back to Palatino and Georgia. The game stays playable without those fonts.
